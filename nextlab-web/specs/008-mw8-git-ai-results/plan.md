# Implementation Plan: MW8 — Git & AI Results

**Branch**: `008-mw8-git-ai-results` | **Date**: 2026-05-27 | **Spec**: `specs/008-mw8-git-ai-results/spec.md`

## Summary

MW8 adds git repository submission for students (alternative to file upload) and three read-only analysis report pages for docentes and codocentes. The student submits a single URL; the backend drives all analysis. The frontend displays whatever the API returns with no business logic.

## Technical Context

**Language/Version**: TypeScript 5.9 strict, React 19

**Primary Dependencies**: Vite 8, Tailwind CSS v4, React Router v7, axios

**Storage**: N/A (stateless frontend)

**Testing**: React Doctor quality gate after implementation complete

**Target Platform**: Web browser (SPA)

**Project Type**: Feature addition to existing React SPA

**Performance Goals**: Report pages load within 3 seconds of navigation (SC-002)

**Constraints**: No external UI libraries; no business logic on client (Constitution VII)

**Scale/Scope**: 5 new files, 4 updated files, 9 routes

### src/components/student/GitSubmissionForm.tsx (NEW)

Props:
```ts
{
  actividadId: string
  existingSubmission: SubmissionResponse | null
  isPastDeadline: boolean
  onSuccess: (submission: SubmissionResponse) => void
}
```

Mode FSM: `'form' | 'submitting' | 'confirmed' | 'editing' | 'updating' | 'closed'`

Derived at render:
- `existingSubmission && mode !== 'editing'` → confirmed
- `isPastDeadline && !existingSubmission` → closed
- else → form

System account note: `import.meta.env.VITE_GIT_SYSTEM_ACCOUNT ?? 'nextlab-bot'`

Validation: `repoUrl.trim() === ''` or `!repoUrl.includes('://')` → inline error, no API call.

### src/pages/docente/SubmissionDetailPage.tsx (UPDATED)

Extended state shape from navigate:
```ts
{ item: SubmissionListItem; actividadTipo?: ActividadTipo; actividadFlags?: ActividadFlags }
```

Where `ActividadFlags = { git_enabled: boolean; ai_enabled: boolean; detection_enabled: boolean }`.

`SubmissionsPage` passes `actividadFlags` from the fetched `Actividad` object.

Route prefix derived from `useLocation().pathname` (`/codocente` vs `/docente`) for building report links.

### Report pages (NEW — all follow same pattern)

```
GitAnalysisPage  → GET /submissions/:subid/git-analysis   → commit table + stats
AIReportPage     → GET /submissions/:subid/ai-report       → sections list
DetectionReportPage → GET /submissions/:subid/detection-report → score + flagged segments
```

All have:
- `useParams` for `:cid`, `:aid`, `:subid`
- `useLocation().pathname` to build back link
- Pending / error / done rendering
- `LoadingSpinner` during fetch
