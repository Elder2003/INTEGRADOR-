# Data Model: M6 — AI Router

## Migration: 000006_ai_router

### Table: router_configs

Append-only history of routing mode changes. Constitution Principle I — no UPDATE or DELETE.

```sql
CREATE TABLE IF NOT EXISTS router_configs (
  id          UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  mode        TEXT        NOT NULL CHECK (mode IN ('local', 'auto', 'cloud')),
  prev_mode   TEXT        CHECK (prev_mode IN ('local', 'auto', 'cloud')),
  changed_by  UUID        REFERENCES users(id),  -- NULL = system/seed entry
  changed_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Current mode is always the most recent row
CREATE INDEX IF NOT EXISTS idx_router_configs_changed_at
  ON router_configs(changed_at DESC);
```

**Active mode query**:
```sql
SELECT mode FROM router_configs ORDER BY changed_at DESC LIMIT 1;
```

**Field notes**:
- `prev_mode` — NULL on the very first (seed) row; populated on all subsequent changes for full diff history.
- `changed_by` — NULL for the system-generated seed row on first startup; references `users(id)` for all admin-initiated changes.
- No `UPDATE`, no `DELETE` — ever.

### Table: ai_request_logs

Immutable record of every routing dispatch. Constitution Principle I — no UPDATE or DELETE.
Prompt and completion content are NEVER stored (FR-011).

```sql
CREATE TABLE IF NOT EXISTS ai_request_logs (
  id              UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  request_id      UUID        NOT NULL,           -- caller-assigned idempotency key
  mode            TEXT        NOT NULL CHECK (mode IN ('local', 'auto', 'cloud')),
  backend_used    TEXT        NOT NULL CHECK (backend_used IN ('local', 'cloud')),
  fallback_used   BOOLEAN     NOT NULL DEFAULT false,
  fallback_reason TEXT,                           -- e.g. 'primary_timeout', 'primary_error'
  latency_ms      INT         NOT NULL,
  status          TEXT        NOT NULL CHECK (status IN ('success', 'failed')),
  error_detail    TEXT,                           -- backend error message only, no prompt content
  logged_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS idx_ai_request_logs_logged_at
  ON ai_request_logs(logged_at DESC);

CREATE INDEX IF NOT EXISTS idx_ai_request_logs_request_id
  ON ai_request_logs(request_id);
```

**Field notes**:
- `request_id` — UUID generated by the caller (or the router itself if caller omits it); used for idempotency checks and cross-system tracing.
- `fallback_reason` — populated only when `fallback_used = true`; values: `primary_timeout`, `primary_error`, `primary_unreachable`.
- `error_detail` — short error message from the backend (e.g. HTTP status + message). MUST NOT contain any portion of the prompt or completion.
- No `UPDATE`, no `DELETE` — ever.

## Validation Rules

| Table | Rule |
|---|---|
| `router_configs.mode` | Must be one of: `local`, `auto`, `cloud` |
| `router_configs.prev_mode` | NULL only on the first seed row; must match a valid mode otherwise |
| `ai_request_logs.backend_used` | `local` or `cloud` only (not `auto` — `auto` is a routing strategy, not a backend) |
| `ai_request_logs.fallback_reason` | Required when `fallback_used = true`; NULL when `fallback_used = false` |
| `ai_request_logs.error_detail` | Required when `status = 'failed'`; should be NULL when `status = 'success'` |

## Startup Seed

On `Service.init()`, if `router_configs` is empty:

```sql
INSERT INTO router_configs (mode, prev_mode, changed_by, changed_at)
VALUES ('local', NULL, NULL, NOW());
```

This guarantees the "current mode" query always returns a result.
